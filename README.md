# 智途 AI · 人工智能职业规划平台

面向人工智能专业学生的中文职业探索与成长工作台。基于 [CareerCase](https://github.com/KamalReddy2901/careercase)（MIT）二次开发，重做中文内容、全站视觉、交互与静态部署入口。

## 已实现

- 生涯概览：兴趣雷达、规则推荐、学习进度与下一步任务。
- 自我探索：18 道兴趣题、10 项技能自评、6 维价值偏好。
- 职业方向：大模型应用、机器学习、计算机视觉、自然语言处理、数据分析、AI 产品；支持搜索、分类、双方向对比和能力差距查看。
- 成长路线：每个方向 4 阶段、12 个任务，按每周可投入时间调整周次；任务勾选与学习复盘自动保存。
- 学习资源：12 份官方平台学习资料，支持分类、语言筛选、搜索与收藏。
- 个人档案与报告：JSON 导入导出、空白/示例档案切换、Markdown 报告下载、浏览器打印或保存 PDF。
- 设计：深海蓝与薄荷绿、SVG 神经网络动效、兴趣雷达、时间线、移动端导航，以及系统减少动态效果适配。

## 本地运行

使用 Node.js 22 或 24：

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

构建与检查：

```sh
npm run qa:zhitu
npm run qa:guidance-regression
npm run build
npm run preview
```

Windows 也可运行项目根目录的 `启动预览.ps1`。首次运行前需要安装依赖。请通过 HTTP 地址访问；不要双击 `dist/index.html`。

## 发布网址

已经提供 `.github/workflows/pages.yml`，完整流程见 `docs/部署说明.md`。将代码放入自己的 GitHub 仓库后，在 **Settings → Pages → Source** 选择 **GitHub Actions**。推送 `main` 分支后，工作流会检查、构建并部署 `dist`。

采用相对资源路径与 HashRouter，兼容 GitHub Pages 的仓库子目录；刷新 `/#/roadmap` 等页面不需要服务器路由。也可把构建后的 `dist` 上传到静态托管服务。

网站入口：[智途 AI](https://wpc666-create.github.io/zhitu-ai-career/)。首次发布完成后可访问；部署状态见本仓库的 Actions 页面。

## 数据与算法

中文数据在 `src/zhitu/data.ts`，平台逻辑在 `src/zhitu/model.ts`。岗位技能等级、兴趣画像与计划时长属于课程学习用途的教学数据，不是实时招聘统计、薪资预测或标准化心理测评。学习链接核查时间为 2026-10-15，外部平台可能更新。

复用上游 RIASEC 评分函数，将题目适配为 18 个 AI 学习场景。匹配参考分由兴趣 50%、能力 35%、价值偏好 15% 组成；未完成的维度不计入，并对其余权重重新归一化。技能差距复用上游的证据加权算法；未接触技能使用零证据置信度。推荐是可解释的规则计算，不需要模型 API，也不是录用概率。

首次访问载入明确标注的示例档案。建立个人空白档案后，只有完成对应自评才生成相关分数。数据仅保存在当前浏览器的 localStorage；没有账号、服务器数据库或跨设备自动同步。换设备或清理浏览器前请导出备份。
